# beats.json 字段与写稿规矩

整个片子只有这一个数据源。改文案 = 改这里 + 重跑 `run.py`，不用碰代码。

## 顶层字段

| 字段 | 默认 | 说明 |
|---|---|---|
| `aspect` | `"9:16"` | `9:16` / `16:9` / `1:1` / `4:5`。字号按短边、位置按高比例推导，换画幅不用改代码 |
| `output` | `"final.mp4"` | 相对项目目录的成片文件名 |
| `watermark` | `""` | 右上角水印文字，留空则不画。要账号名就写这里 |
| `poster_crop_bottom_ratio` | `0.04` | 裁掉海报底部这一比例，用于去掉 AI 出图的右下角角标 |
| `voice.voice` | `zh-CN-YunxiNeural` | 见下面音色表 |
| `voice.rate` | `"+6%"` | 语速。信息密度高就 `+12%`，要沉稳就 `+0%` |
| `voice.head` | `0.24` | 每拍开头留给标题拍入的空档（秒） |
| `voice.tail` | `1.06` | 句尾呼吸（秒）。**这个数决定整片节奏松紧** |
| `bgm.enabled` | `true` | 关掉就只剩人声和音效 |
| `bgm.source` | `"synth"` | `synth` 程序化合成 / `file` 用外部音乐文件 |
| `bgm.file` | — | `source: file` 时必填，相对项目路径，如 `audio/bgm.mp3` |
| `bgm.start` | `0.0` | 从曲子第几秒开始取，用来跳过前奏 |
| `bgm.duck` | `0.72` | 人声起来时音乐压低的比例，0.72 = 压到 28% |
| `bgm.bpm` | `112` | 合成用。112 偏轻快，96 更从容，128 更抓 |
| `bgm.gain` | `0.30` | 音乐底噪。合成 0.22–0.38，外部曲子 0.45–0.55 |
| `bgm.mood` | `"bright"` | 合成用。`bright` 带鼓组 / `calm` 只有拨弦和铃 |
| `posters` | — | `{"1": "keyframes/kf_1.jpg", ...}`，键是拍号 |
| `beats` | — | 分镜数组，顺序即播放顺序 |

## 单拍字段

| 字段 | 必填 | 说明 |
|---|---|---|
| `id` | 建议 | 拍号，从 1 开始。渲染时决定装饰件从左还是从右进（奇数左、偶数右） |
| `title_cn` | 否 | 画面大字，2–5 字最佳。留空则不出现标题条 |
| `narration` | 是 | 这句配音的全文，也是字幕原文 |
| `poster` | 否 | 单独指定海报，覆盖 `posters` 映射（同一张图给多拍用） |
| `dur` / `narration_dur` | 自动 | `tts.py` 回写，不要手改 |

## 时长怎么算

```
单拍 dur = narration_dur + head + tail
整片时长 = Σ dur
```

一条 20–30 秒的片子 = 6 拍 × 每句 2.5–3 秒旁白。经验值：

- 中文 TTS 约 **4.8 字/秒**（`rate=+6%`）
- 一句话 **12–18 字**最稳；超过 22 字字幕要占两行，画面会挤
- 想凑到某个时长，**先改字数，不要硬调语速**。语速超过 +18% 会像念稿机

## 写旁白的四条硬规矩

1. **一句一个信息点。** 一句话里塞两个概念，观众一个都记不住。
2. **口语，不是文案。** 读出来顺不顺，用耳朵判断：能不能一口气念完不断气。
3. **每拍之间要有推进关系。** 问题 → 做法 → 过程 → 结果，或者 是什么 → 怎么用 → 谁受益。
4. **标题和旁白不重复。** 标题是"两个字的标签"，旁白负责解释。标题写"先拼海报"，旁白就别再说"先拼海报"。

## 音色表（edge-tts，免费）

| 音色 | 感觉 | 适合 |
|---|---|---|
| `zh-CN-YunxiNeural` | 年轻男声，偏轻快 | 产品介绍、教程（默认） |
| `zh-CN-YunjianNeural` | 低沉男声，有力量 | 悬念、严肃议题 |
| `zh-CN-XiaoxiaoNeural` | 温柔女声 | 生活、亲子、种草 |
| `zh-CN-XiaoyiNeural` | 少女声，活泼 | 轻松吐槽、二创 |
| `zh-CN-YunyangNeural` | 播音腔男声 | 新闻、正式说明 |

试听不用出片，直接：

```bash
python scripts/tts.py <proj> --voice zh-CN-XiaoyiNeural --rate "+10%"
```

## 只改文案后的最小重跑

```bash
python scripts/tts.py <proj>     # 重生成配音 + 回写时长（约 10 秒）
python scripts/render.py <proj>  # 重渲画面（6 拍约 2–3 分钟）
```

如果只动了海报、文案没动，跳过 tts：`python scripts/render.py <proj>`。
如果只动了 BGM 参数，连画面都不用重渲——直接重跑 `render.py` 也行（它每次都整体重来，不会拼接错位）。
